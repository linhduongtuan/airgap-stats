How the phases connect

Phase 0 was the only true bottleneck: it decided how missing data, confounder selection, and the SEM item estimator would be handled, and those decisions had to be on paper before Phase 2/3 code was written, or every later result would be post-hoc. Phase 4 only needed Phase 0 and ran in parallel with 1–3; it fed a more realistic test bed into both tracks once ready (dashed). All of it has now landed, in that order.

Solid arrows: hard dependency. Dashed arrows: Phase 4 improves Phase 2/3's test coverage but wasn't required to start them. All seven phases shipped, in this dependency order.

Medical / epidemiological track ✓ Shipped

Move the crude→adjusted logistic-regression pipeline from a textbook default to methods that hold up under real clinical-data quirks.

Medical Depended on: Phase 1

example-clinical and crp-mortality both fit a single crude and a single adjusted logistic regression via plain MLE on complete cases — fragile at this sample size in specific, well-known ways. Reference implementation: tools/medical_track/ (Python); Firth's IRLS is hand-implemented in base R too, cross-validated against R's own logistf package to ~1e-7 agreement.

3

SEM / survey track ✓ Shipped

Bring the measurement and mediation models up to current reporting standards for structural equation modeling.

SEM Depended on: Phase 1

burnout-mediation and example-survey-sem both fit CFA and mediation models with ML estimation on Likert items and reported point estimates without bootstrap CIs. The ordinal estimator and bootstrapped indirect effects change the numbers a reviewer would actually see, not just their precision.

R turned out more capable than Python here. semopy (the Python SEM library) has no genuine multi-group SEM and its WLS solver stalls on a joint measurement+structural fit at this model size — both are semopy limitations, not fundamental to the method. Python works around them (per-group fits + bootstrap for invariance; two-step factor-score regression for mediation). lavaan (R) does both natively: real multi-group SEM with a chi-square difference test, and a one-step joint fit with native bootstrap SE in under two minutes. The R scripts use lavaan's native approach directly rather than porting Python's workarounds.
ImprovementWhy it mattersTouchesPriorityEffortStatus
Ordinal (WLSMV/DWLS) estimator 5-point Likert items are ordinal, not continuous. Polychoric correlations with WLSMV/DWLS change loadings, fit indices (CFI/TLI/RMSEA/SRMR), and standard errors versus ML-on-continuous. burnout-mediation, example-survey-sem

Synthetic data fidelity ✓ Shipped

Let Stage D catch convergence and separation problems, not just syntax errors — without ever exposing a real value.

Cross‑cutting Depended on: Phase 0

The default synthesizer generates every column independently, by design, so the SEM scripts are written to expect non-convergence on synthetic data — Stage D could only prove "the code runs," never "the model behaves reasonably." An opt-in, still-local, still-reviewed correlated synthesizer (Stage B2) closed that gap, in both languages.

ImprovementWhy it mattersTouchesPriorityEffortStatus
Opt-in correlated synthesizer A Gaussian-copula-style "Stage B2," reviewed locally exactly like dataset_pattern.csv, approximates real pairwise correlation without ever touching real values — enough for the logistic/SEM models to actually converge during testing. r-scripts/synthesize_correlated.R
